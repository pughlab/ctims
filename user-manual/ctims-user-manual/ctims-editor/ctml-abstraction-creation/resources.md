# Resources

When abstracting a clinical trial there are sometimes resources that may help either by verifying the exact cancer type name, protein changes, mapping a drug class to the NCI Thesaurus (NCIt) terms.

* **OncoTree**: A cancer classification system by both histological and molecular traits, managed by Memorial Sloan Kettering Cancer Center (MSK)  [https://oncotree.mskcc.org/#/home](https://oncotree.mskcc.org/#/home)
* **HGNC**: HUGO Gene Nomenclature Committee, a resource for approved human gene nomenclature [https://www.genenames.org/](https://www.genenames.org/)
* **OncoKB:** An FDA-recognized precision oncology knowledge base maintained by MSK. It maps thousands of cancer gene alterations to biological effects and approved therapies. [https://www.oncokb.org/](https://www.oncokb.org/)
* **CIViC**: Clinical Interpretation of Variants in Cancer, a knowledge base for expert-moderated cancer variant curation [https://civicdb.org/](https://civicdb.org/)
* **MyCancerGenome:** precision oncology reference tool developed by Vanderbilt University Medical Center [https://www.mycancergenome.org](https://www.mycancergenome.org)
* **NCIt**: NCI Thesaurus is a comprehensive, science-based biomedical vocabulary and reference terminology. Managed by the National Cancer Institute (NCI)'s Enterprise Vocabulary Services, it functions as a foundational dictionary for clinical care, translational research, and biomedical coding [https://evsexplore.semantics.cancer.gov/evsexplore/welcome](https://evsexplore.semantics.cancer.gov/evsexplore/welcome)
